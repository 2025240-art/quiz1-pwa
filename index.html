왜 2단계 하이브리드 방식인가요?

복잡한 유료 API Key 발급 없이, 본인이 보유한 Google 제미나이(Gemini) 웹 또는 나만의 젬(Gem)을 그대로 활용해 영상 요약과 인터랙티브 퀴즈를 즉시 화면으로 변환하는 스마트 워크플로우입니다.

사전 준비 제미나이 젬(Gem) URL 준비 방법

• 직접 만든 제미나이 젬이 있다면 해당 젬의 주소(https://gemini.google.com/gem/...)를 입력해 두세요. 브라우저에 자동 저장되어 다음 방문 시 다시 입력할 필요가 없습니다.

• 별도 젬이 없거나 입력창을 비워두어도 기본 제미나이(https://gemini.google.com/app)가 자동으로 열리므로 누구나 바로 사용할 수 있습니다.

3단계 초간단 이용 절차

1
YouTube URL 입력 후 [1단계: 프롬프트 복사 & 이동] 클릭

학습할 유튜브 영상 주소를 넣고 1단계 버튼을 누르면, 영상 분석 및 JSON 출력 규칙이 담긴 전용 프롬프트가 클립보드에 자동 복사되며 새 탭에서 제미나이 창이 열립니다.

2
열린 제미나이 창에 붙여넣기(Ctrl+V / Cmd+V) 후 전송

제미나이 채팅 입력창에 복사된 프롬프트를 그대로 붙여넣고 전송(Enter)하세요. 잠시 후 제미나이가 요약과 퀴즈가 담긴 JSON 결과를 출력합니다.

3
응답 복사 후 [2단계: 퀴즈 자판기 뽑기] 클릭

제미나이가 출력한 답변 우측 상단의 [코드 복사] 버튼을 누른 뒤, 다시 이 페이지의 2단계 입력창에 붙여넣고 뽑기 버튼을 누르면 요약 카드와 인터랙티브 퀴즈가 완성됩니다!
